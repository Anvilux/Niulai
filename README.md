# 牛来 · 3D 横版跳跃（网页版）

牛市来了，快跑！一只叫「牛来」的小牛在 3D 草原上狂奔，躲蛇、跨坑、捡红蜡烛涨牛气。

## 在线玩

- 仓库已开启 GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `/ (root)`
- 开启后地址形如：`https://Anvilux.github.io/Niulai/`

## 本地运行

因为要加载 3D 模型，必须通过 HTTP 打开（直接双击 index.html 会因 `file://` 限制无法加载模型）：

```bash
cd Niulai
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

## 操作

| 操作 | 按键 |
|---|---|
| 跳跃 / 二段跳 | 空格 / ↑ / W |
| 喊妈妈（技能） | J |
| 开始游戏 | 点击画面任意位置 |

手机上请**横屏**游玩。首次加载需要下载约 15 MB 的 3D 模型，请保持页面打开。

## 目录结构

```
index.html          游戏主页面（自包含，含开始界面、UI、分享海报逻辑）
models/*.glb        3D 模型（牛来 / 妈妈 / 蛇，已量化 + 减面压缩）
bgm/*.wav           背景音乐 4 段（开始界面 / 主跑酷 / 大牛市爆发 / 跌停结算）
```

## 玩法要点

- 捡红色蜡烛（阳线）涨牛气，避开绿色蜡烛（阴线）
- 牛气攒满 100 触发「大牛市」：无敌 + 双倍分
- 结算页可以点「分享战绩」生成战绩海报（手机端保存到相册，电脑端下载图片）

## 技术栈

Three.js（WebGL）+ 原生 JS，纯前端、无后端依赖。
